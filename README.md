# 🎓 Claude Academy

A complete, self-contained skill training website that teaches everything about Claude AI — from beginner to expert.

## 📚 What's Included

**12 Chapters** covering:
- What is Claude? (Anthropic, LLMs explained simply)
- How LLMs Actually Work (tokens, context windows, training)
- The Claude Model Family (Haiku, Sonnet, Opus)
- Prompting 101 (system prompts, the 6-part framework)
- Advanced Prompt Engineering (chain-of-thought, few-shot, XML tags)
- Claude's Capabilities (vision, coding, long context)
- Claude's Limitations (hallucination, knowledge cutoff)
- The Claude API (REST, SDKs, streaming)
- Tool Use & Function Calling (agentic tool loops)
- Agentic Claude & Workflows (multi-agent patterns)
- Safety, Ethics & Constitutional AI
- Claude in Production (RAG, caching, evaluation)

## ✨ Features

- **Personalised start** based on your role (newbie, engineer, business, etc.)
- **Funny quiz** after each chapter with instant feedback and explanations
- **Progress tracked** in browser localStorage — persists across visits
- **XP system** — earn points as you complete chapters
- **Real-world examples** throughout every chapter
- **Interactive code blocks** with syntax highlighting
- **Responsive** — works on mobile and desktop
- **Zero dependencies** — pure HTML/CSS/JS, no frameworks
